# 🍀 Lotofácil Game Generator

Projeto desenvolvido em **Python** para gerar combinações de números para apostas na **Lotofácil**, uma das loterias mais populares do Brasil.

O programa cria jogos aleatórios seguindo as regras da Lotofácil, garantindo que os números não se repitam dentro do mesmo jogo.

Além disso, o projeto pode utilizar **dados históricos de sorteios armazenados em planilha Excel**, permitindo trabalhar com resultados reais da loteria para possíveis análises futuras.

Este projeto foi desenvolvido como parte dos meus estudos em **programação Python e lógica de programação**.

---

# 🚀 Funcionalidades

- Geração automática de números da Lotofácil
- Números únicos em cada jogo
- Possibilidade de gerar múltiplos jogos
- Exportação dos jogos gerados para arquivo
- Possibilidade de utilização de dados históricos da Lotofácil em planilha Excel

---

# 📊 Base de dados

O projeto pode utilizar uma planilha **Excel (`lotofacil_data.xlsx`)** contendo resultados reais de sorteios da Lotofácil.

Esses dados podem ser utilizados para:

- análise de resultados anteriores
- estudos estatísticos
- futuras melhorias no algoritmo de geração de jogos

---

# 🛠 Tecnologias utilizadas

- **Python**
- **Excel (.xlsx)** para armazenamento de dados históricos
